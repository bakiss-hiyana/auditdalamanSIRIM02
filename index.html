🔧 Pembaikan Bug

🐛 Bug 1 — ImportError: cannot import name 'authenticate'

Punca: import streamlit dipanggil sebelum sys.path ditetapkan. Python tidak dapat cari utils.py apabila Streamlit jalankan dari direktori luar.

✅ Dibetulkan: sys.path.insert() kini di baris paling atas semua fail — sebelum sebarang import lain.

🐛 Bug 2 — Menu sidebar tidak boleh diklik / tidak berfungsi

Punca: Streamlit mengesan folder pages/ secara automatik sebagai sistem navigasi multi-page — ini mengatasi st.radio navigasi manual kita.

✅ Dibetulkan: Semua fail modul dipindahkan dari pages/ ke folder baharu modules/ yang tidak dikenali Streamlit sebagai folder navigasi automatik.
✅ Kedua-dua bug telah diperbaiki. Jalankan streamlit run sirim_audit/app_sirim.py dan semua menu berfungsi sepenuhnya.
